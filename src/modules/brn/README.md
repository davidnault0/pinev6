# 💲 BRN (Big Round Numbers) Module

## Description
Identifies and displays key psychological price levels at major round numbers (00, 50, etc.). These levels often act as support/resistance due to institutional and retail trading behavior.

## Features
- Automatic detection of round numbers (e.g., 1.0000, 1.0050, 1.0100)
- Configurable interval (every 50, 100, 500 points)
- Subtle visualization to avoid chart clutter
- Optional alerts when price approaches BRN levels

## Usage
Useful for:
- Identifying potential reversal zones
- Setting take profit targets
- Understanding price rejection areas
- Combining with other support/resistance analysis
